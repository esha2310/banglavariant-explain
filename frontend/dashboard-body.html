Ancestry is context. Not a verdict.

South Asian ancestry is not the same as Bangladeshi nationality. Allele frequency needs the correct build, allele, dataset version, allele count and denominator.

Interpretation guardrails

LITERATURE EVIDENCE

Read the paper behind the keyword.

Actual TF-IDF retrieval over a small CC BY abstract collection. Gene-level matches may not discuss your exact variant. No LLM summary, clinical evidence grade or factual entailment is inferred.

LOCAL VCF WORKSPACE

Check coordinates. Keep data local.

Exact-coordinate lookup against the three bundled records. No normalization, liftover, genotyping or clinical interpretation. Do not upload personal genetic data.

Only chromosome, position, REF and ALT are read. Sample/genotype columns are ignored. Data stays in page memory and is excluded from saved records and reports.

MODEL TRANSPARENCY

A status, not a made-up score.

This release implements source annotation and lexical NLP. Pathogenicity prediction requires a separate, leakage-aware and independently evaluated research study.

The implemented pipeline

01 · Exact lookup

Supported aliases or exact VCF build + chromosome + position + REF + ALT. No fuzzy variant conversion.

02 · Source record

Recorded classification, review status, update date and consequence. Review status is not ML confidence.

03 · Literature retrieval

TF-IDF title + abstract cosine. No automatic interpretation or generative medical summary.

The bundled records are not representative of Bangladesh. Source classifications may change and are condition dependent. Population AF, conservation scores and personal phenotypes are not integrated. No patient uploads are retained by app code; hosting providers still receive normal request logs. Generated hero artwork is decorative. How to use the demo

Open Variant search, inspect one example, read Population context, then search the literature. Verify original sources. Export PDF for a descriptive snapshot, not a medical report. Real sign-in/sign-up runs only on the included FastAPI server; public static pages use Guest mode.
